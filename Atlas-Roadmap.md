# Atlas Roadmap

A personal productivity dashboard built with React and Bootstrap.

---

# Project Vision

Atlas is designed to reduce mental load by giving users a single place to manage daily work, goals, habits, schedules, and progress.

The philosophy is simple:

> Help the user answer one question:
>
> **"What should I focus on next?"**

---
